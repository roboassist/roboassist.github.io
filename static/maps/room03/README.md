# Room semantic scene explorer

This static WebGL module uses the user-supplied `room03_web_map.zip`. Its input data files were verified against the archive's SHA256SUMS before integration. Website annotations now include the user's explicit corrections below. The current scene is named `room`, with 29 consecutively numbered objects `room:FG-01` through `room:FG-29`. Historical identifiers are preserved in `legacy_object_id`, the alias map and audit. Renumbering changes no geometry, RGB, bounds or display sizes.

## Website integration

The homepage's **Semantic Map** section (`#semantic-map`) appears after Robot Demonstrations and before Experiments. Its cover is a screenshot of the supplied scene, generated by the explorer. `static/js/semantic-map-section.js` sets the iframe source only when the visitor clicks **Explore in 3D**. The frame pauses rendering while closed or outside the viewport. The full explorer is also available at `static/maps/room03/`; the asset directory retains its original name for URL compatibility, while all scene headings display **Room**.

Run the existing preview server from the repository root:

```powershell
python tools/preview.py --port 8772
```

Open `http://127.0.0.1:8772/#semantic-map` or `http://127.0.0.1:8772/static/maps/room03/`.

This module requires HTTP(S) and WebGL. No build step or ROS service is needed. Three.js 0.180.0 and its two loaders/controls are vendored locally with the MIT license in `vendor/LICENSE`; the explorer makes no third-party network requests.

## Features

- Orbit, zoom and pan using OrbitControls; smooth object focus, top view and reset.
- Search by label or instance ID; filter categories and select individual objects.
- Click point geometry to inspect an instance; hover shows its label and ID.
- Original RGB or category colors; dim nonselected objects or isolate selection.
- Optional environmental cloud and object bounds; adjustable point size.
- Extent, center, source detection count and geometry review hints in the inspector.
- Mobile catalog and a Details drawer; keyboard-operable lists and controls.
- Instance deep links using `?object=room%3AFG-26`; historical `room03:FG-55` links resolve to the same aluminum box.
- Same-origin selection event `roboassist:semantic-object` for later coordination with the site's other modules. It contains `sceneId`, `objectId` and `label`.
